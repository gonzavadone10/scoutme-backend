# ScoutMe Backend

## Descripción

Backend de ScoutMe desarrollado con Node.js y Express.

Este proyecto proporciona los servicios necesarios para la autenticación de usuarios y la comunicación entre la aplicación web y la aplicación móvil.

## Tecnologías utilizadas

* Node.js
* Express
* CORS
* JavaScript

## Instalación

```bash
git clone https://github.com/gonzavadone10/scoutme-backend.git
cd scoutme-backend
npm install
```

## Ejecución

```bash
npm start
```

Servidor disponible en:

```txt
http://localhost:4000
```

## Funcionalidades

* Registro de usuarios
* Inicio de sesión
* Gestión de perfiles
* Comunicación con frontend web
* Comunicación con aplicación mobile

## Endpoints principales

### Autenticación

```txt
POST /api/auth/register
POST /api/auth/login
```

### Contacto

```txt
POST /api/contact
```
